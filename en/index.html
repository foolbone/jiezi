01
Story Bible

Build the world before you write it

The worst thing about long novels is forgetting what you set up thirty chapters ago. Jièzǐ breaks your world into maintainable files: characters, locations, factions, rules, customs — independent yet interconnected.

  • Character files: full fields + custom fields; desires, fears, flaws, and arcs at a glance; relationships, appearances, and status tracked
  • Worldbuilding entries: custom categories, hierarchical structure, bidirectional links and tags
  • World rules: priority-ranked, checked during writing for consistency — no more plot holes
  • Reverse index: change one setting and instantly see every chapter and outline that references it
02
Story Board

Lay the skeleton before the flesh

Outlines shouldn't be dead tables in a document. Volumes, acts, chapters, and scenes drag-and-drop freely; when multiple storylines run in parallel, swimlane timelines keep track of who's advancing what and where the foreshadowing hides.

  • Multi-level outline tree: Volume / Act / Chapter / Scene, drag to reorder, convert to chapters anytime
  • Kanban view: flow by status — "Ideas → Writing → Done"
  • Story timeline: multi-swimlane parallel narrative, sorted by in-story time, independent of writing order
  • Foreshadowing tracker: plant → payoff tracked end to end — the system remembers what you still owe
03
Writing Studio

Focus on the chapter at hand

The editor is built for long writing sessions: serif body text, adjustable line height and column width, night and eye-care parchment themes. Your lore never interrupts you — it floats up exactly when you need it.

  • Immersive editor: focus mode, typewriter mode, night mode, progressive dimming of inactive paragraphs
  • Lore linking: any character, place, or entry in your text — hover to view its file, no tab switching
  • Auto-save: every change writes to disk instantly, roll back to any historical version
  • Live word count: cursor position, word count, character count pinned to the bottom
04
Writing Cockpit

See the whole book at a glance

Writing is a marathon — you need a dashboard, and milestones. The cockpit lays out "where I am, how far I've come, what's still owed" on one screen, so you write by data, not by feeling.

  • Writing progress: total word count, goal progress, chapter / character / location / event stats
  • Today & streak: daily goal completion rate, consecutive writing days
  • Writing heatmap: 20 weeks of activity at a glance, see your own rhythm
  • Todos & reminders: unresolved foreshadowing, unwritten chapters — the system keeps track

09

Frequently asked

A few things about data, connectivity, and AI — stated clearly up front.

Where is my work stored?
By default in ~/Documents/Jièzǐ: settings, outlines, and timelines as JSON, chapter text as Markdown — all open formats. Change the directory in Settings, e.g. to an iCloud or sync folder.
Do I need internet or an account?
No. All core features work fully offline: Story Bible, outline, writing, export, and cockpit. There is no account system, no cloud dependency, and no data collection.
Is the AI assistant required?
No. Without an API key, every offline feature works normally. To use AI, enter a Base URL and key in Settings — DeepSeek is preconfigured, and any OpenAI-compatible endpoint (Qwen, Kimi, Volcengine, local Ollama) works.
Which platforms are supported?
macOS (Apple Silicon), Windows (x64), and an Android beta; iOS is in development. Full desktop features like DOCX / EPUB / PDF export require the desktop app.
What export formats are supported?
TXT, Markdown, DOCX, EPUB, and PDF — plus a full-book JSON backup. Export once, take it anywhere. No platform lock-in.
Can I lose my writing?
No. Auto-save writes to disk every 2 seconds; each chapter keeps version snapshots for rollback; projects also have an automatic backups/ directory.
